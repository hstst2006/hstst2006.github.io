Every self respecting blog needs a clichéd first post. This is that post. This blog is likely going to be programming related, so "Hello, world!" is the only proper choice of title for this first post. "Hello, world!" shows that everything works as intended before you start doing more serious work.

Since this is the first blog post (and a test page), I can use this opportunity to see how the markdown formatting looks on the github pages-page for my own future reference. This way I can see how the formatting looks without depending on the "Welcome to Jekyll" blogpost that was graciously supplied with this project template.

Among the included examples were the `file name formatting` of the blogposts in the `_posts` folder: `Year-Month-Date-title.md`
There were also some examples on how to format code using tripple \` backtics like so:
```bash
# This is a bash code block
# Don't try this at home
sudo rm -rf /
```
Lastly among the examples some links were thrown in to show it was done. [This one](https://hstst2006.github.io/) just takes you back to the homepage.
